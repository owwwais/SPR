## P3 — صفحة الهبوط بـ GSAP وLenis وReact Bits

| القسم | الأداة |
|---|---|
| **البطل** | خلفية **DotGrid** تتفاعل مع المؤشر باللون الأخضر المزرق · عنوان بخط 100px يصعد **كلمةً كلمة** · زر رئيسي بـ **Magnet** · ثلاث شاشات حقيقية من المنتج تتبدّل في **CardSwap** (درجة الملاءمة، ومهمة المقابلة، والوظائف المرشّحة) |
| **العبارة الافتتاحية** | **ScrollReveal**: تتضح كلمةً كلمة مع التمرير |
| **«هكذا يفكّر حكيم»** | مشهد **مثبّت بـ GSAP ScrollTrigger**: السيرة ← الحقائق ← أشرطة المعيار مع عدّاد يصل إلى 82 ← «القرار لك». وعلى الجوال أو مع تقليل الحركة تظهر الخطوات الأربع متتالية دون تثبيت |
| **المنتج** | شبكة bento غير متماثلة من **SpotlightCard** يتبع فيها ضوءٌ المؤشر، وتدخل بـ **AnimatedContent** |
| **المقابلة الافتراضية** | غرفة مقابلة مصغّرة، وخطوات التقييم السبع تُعلَّم بالتتابع، **مع شارة «قريباً»** لأن الميزة لم تُطلق بعد |
| **الإنصاف** | الخصائص التي نتجاهلها **تُشطب واحدة واحدة** بـ GSAP، والخط يُرسم من بداية القراءة |
| **الباحثون** | بطاقات تتراكم بـ CSS sticky، وهو يعمل مع Lenis لأنه يُبقي التمرير الأصلي |
| **الخاتمة** | **SplitText** للعنوان، و**Magnet** للزر |
| **التمرير** | **Lenis** على هذه الصفحة وحدها، متزامن مع ScrollTrigger في حلقة واحدة، **ولا يُحمَّل لمن طلب تقليل الحركة** |

**مكونات React Bits السبعة** في `srp/components/react-bits/`، و**قرأتها كاملة قبل إدخالها**: لا اتصال بالشبكة ولا `eval`. واستبعدت **MagicBento** (1,417 سطراً) و**CardSwap** بنسخته الكاملة لأنهما يجلبان `@hugeicons` غير المعتمدة، وأزلت من CardSwap صوره التجريبية. والرخصة في `LICENSE.md` بجوارها.

**تعديلات العربية على المكونات:** SplitText يقسّم **بالكلمات** افتراضياً لا بالحروف (A1) · ScrollReveal بلا ميلان (كان يدور حول الحافة اليسرى) · CardSwap بلا نص إنجليزي لقارئ الشاشة. وأصلحت ستّ ملاحظات من قواعد React Hooks في الكود المنسوخ بدل تعطيل القواعد.

### الأداء — مقيس على بناء الإنتاج
| | النتيجة | الحد في الخطة |
|---|---|---|
| كود الحركة كله (GSAP + ScrollTrigger + SplitText + Lenis + المكونات السبعة) | **75KB مضغوطاً** | ≤ 100KB |
| **LCP** على جوال متوسط (CPU أبطأ 4× + شبكة 4G سريعة) | **1.04–1.10 ثانية** | ≤ 2.5 |
| LCP على سطح المكتب · CLS | 0.27 ثانية · **0** | — · < 0.1 |
| مع تقليل الحركة | لا عنصر يبقى مخفياً، والقصة تظهر ثابتة | — |

> **اعتراف:** القياس الأول كان **2.66 ثانية**، أي فوق الحد. السبب أن SplitText يُخفي العنوان حتى يكتمل تحميل JavaScript، وهذا يتأخر على الجوال البطيء. **الحل:** العنوان الرئيسي يُقسَّم على الخادم ويُحرَّك بـ CSS من أول رسم، والفقرة الكبرى تظهر فوراً. وبقي SplitText للعنوان الختامي أسفل الصفحة. ثم ظهر في الصور أن قناع الكلمات **يقصّ ذيول الحروف النازلة** (ح، م)، فوسّعته أسفل الكلمة. وكُتبت القاعدة في `DESIGN.md` (A9).

## تكبير المحتوى
حجم الخط الأساسي صار **17px، ثم 18px من عرض 1280px**. كل المقاسات في Tailwind نسبية، فكبرت النصوص والأزرار والمسافات معاً في **كل الصفحات**، بما فيها لوحة الشركات. وصفحة الهبوط بمقياس أكبر: عنوان حتى 100px، وعناوين أقسام 48–72px، ونص 18–20px.

## الدخول بـ Google
زر **«المتابعة باستخدام Google»** في صفحتي الدخول والتسجيل، بتدفق PKCE من Supabase. ونجح ما يمكن اختباره دون مشروع حقيقي:
- التوجيه إلى Google يحمل `provider=google` وتحدي PKCE (S256)، ويُحفظ ملف التحقق في الكوكيز.
- الإلغاء عند Google يعيد المستخدم إلى الدخول مع رسالة عربية واضحة.
- رابط بكود مزوّر ووجهة خارجية (`//evil.example`) **يبقى داخل الموقع**.

والاسم من حساب Google يُملأ مسبقاً في نموذج إنشاء الشركة، للعرض فقط.

## 🔐 ترقية أمنية لم تكن مطلوبة لكنها لازمة
`next` 16.3.3 عليه **ثغرة حرجة** (تنفيذ كود عن بُعد في `next/og`) وست ثغرات أخرى نُشرت بعد أغسطس، وكانت ستُفشل فحص CI لأي PR. **رقّيت إلى 16.3.8** (أول إصدار مُصلَح، صدر قبل 16 يوماً) مع `eslint-config-next` المطابق: **صفر ثغرات في تبعيات الإنتاج**. وما بقي (`braces`) في أدوات التطوير فقط، ولا يصل للمستخدم.

### 🔴 ما تفعله أنت لتفعيل Google
1. **Google Cloud Console** ← APIs & Services ← OAuth consent screen: نوع External، والاسم «حكيم»، وبريد الدعم ونطاقك.
2. **Credentials** ← Create OAuth client ID ← Web application:
   - Authorized JavaScript origins: `https://<نطاقك>`
   - Authorized redirect URIs: `https://<ref>.supabase.co/auth/v1/callback`
3. **Supabase** ← Authentication ← Sign In / Providers ← **Google**: فعّله، والصق Client ID وClient Secret.
4. **Supabase** ← Authentication ← URL Configuration: Site URL = `https://<نطاقك>`، وأضف `https://<نطاقك>/auth/callback` إلى Redirect URLs.
5. تأكّد أن `NEXT_PUBLIC_SITE_URL` مضبوط في Vercel.

قبل هذه الخطوات يعمل الزر، لكنه يعيد المستخدم إلى صفحة الدخول برسالة «تعذّر تسجيل الدخول عبر Google».

## I0 — عقد الوكيل وهيكله

### في `interview-agent/` (الخادم المستقل)
| البند | التفصيل |
|---|---|
| **واجهة المنصة** | `POST/GET/DELETE /v1/platform/interviews` والإلغاء ورمز الجلسة. **كل طلب موقَّع HMAC**، مع نافذة زمنية خمس دقائق، ورفض الطلب المعاد (nonce)، و`Idempotency-Key` للإنشاء |
| **جلسات المتقدم** | رمز Ed25519 صالح 15 دقيقة. **جهاز واحد حيّ**: الرمز الجديد يُبطل القديم. والمؤقّت يحسبه الخادم ويشمل الوقت الإضافي المسموح |
| **دورة الحياة** | آلة الحالات كما في الوثيقة §1.3، وكل انتقال يُسجَّل في `audit_log` |
| **الأحداث** | صندوق صادر (outbox) يُكتب في نفس معاملة التغيير، ويُرسَل موقَّعاً مع إعادة محاولة بتأخير متزايد. **حدث لا يضيع** حتى لو توقف الخادم بين الخطوتين |
| **المحو** | `DELETE` يمحو المقابلة وكل ما تحتها في استعلام واحد |
| **النشر** | `Dockerfile`، والهجرات خطوة منفصلة، و`.env.example` يشرح كل سرّ |

### في حكيم
| البند | التفصيل |
|---|---|
| **هجرة `0019`** | `interview_assignments` و`interview_reports` و`interview_webhook_events`. **`org_id` يُشتق بـ trigger** ولا يُقبل من الكاتب، والقراءة لأعضاء الشركة فقط، والكتابة للخادم وحده |
| **`apply_interview_event()`** | يسجّل الحدث ويطبّق حالته **في معاملة واحدة**. المكرَّر يُتجاهل، والأقدم لا يكتب فوق الأحدث |
| **`interview-gateway`** | إنشاء وإلغاء بصلاحية **شركة الطلب نفسها**. **يحذف الاسم** قبل الإرسال، ولا يرسل الملف أبداً |
| **`interview-webhook`** | يتحقق من التوقيع قبل قراءة أي شيء، و`verify_jwt = false` لأن التوقيع هو المصادقة |
| **الاحتفاظ** | `housekeeping` يمحو المقابلة من الوكيل **قبل** حذف الطلب. إن فشل المحو يبقى الطلب للدورة التالية، فلا تبقى نسخة يتيمة على الخادم الآخر |
| **العقد المشترك** | `contract` و`hmac` **نسختان متطابقتان حرفاً بحرف** في المشروعين، واختبار يفشل عند أي اختلاف |

### التحقق
```
interview-agent   npm test            34/34 (منها قاعدة بيانات حقيقية، و0 متخطّى)
                  typecheck · build   نظيف
srp               tenant_isolation    53/53
                  onboarding          23/23
                  interview_isolation 31/31   ← جديد
                  rls_check           صفر إخفاقات
                  tsc · eslint · build نظيف
Edge Functions    deno check          نظيف (gateway · webhook · housekeeping)
```
**وتجربتان طرفيتان حقيقيتان عبر الحدود** (لم تدخلا CI لأن Deno غير موجود فيه):
1. **الوكيل ← دالة الويب هوك (Deno):** الحدث الصحيح يصل إلى `apply_interview_event` بمعاملاته الصحيحة. السرّ الخاطئ ← 401. والتوقيع لدالة أخرى ← 401. والحدث المعطوب ← 400 دون أي كتابة.
2. **دالة البوابة (Deno) ← الوكيل (Node + Postgres):** الإنشاء نجح، و**الاسم لم يصل الوكيل** رغم وجوده في السيرة المستخلصة. والإعداد الخاطئ رُفض قبل الإرسال. والإلغاء وصل وولّد حدثه.
