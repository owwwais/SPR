### الدفعة 2 — صحة البيانات والأداء
**الإحصائيات كانت تكذب:** الشركة لديها **8,000** طلب والصفحة تعرض **5,000**. كل رقم — المجاميع، المتوسطات، القمع — محسوب على بيانات مبتورة **بلا أي تحذير**. `org_stats()` يجمّع في القاعدة الآن.

| | قبل | بعد |
|---|---|---|
| ترتيب المرشحين (3,250 متقدماً) | **7.63 ms** | **0.270 ms** (**28×**) |
| الخطة | Seq Scan + Hash Join | **Index Scan لعشرين صفاً** |
| الإحصائيات — الصحة | 5,000 من 8,000 ❌ | **8,000 ✅** |
| الإحصائيات — الحمولة | 5,000 صف / **766 kB** | صف واحد / **2.6 kB** (**293×**) |

> **اعتراف:** نسختي الأولى من `org_stats` كانت **70 ms** — أبطأ 10× مما استبدلته، لأن القمع والجدول الزمني كانا يمسحان الجدول 35 مرة. أعدت كتابتها بتجميعتين ⇒ **10 ms**. لولا القياس لشحنتها.

### الدفعة 3 — فرض الحصة (`D16`)
الحصص **من صفحة الأسعار نفسها** لا مخترعة: تجربة 25 · أساسية 150 · نمو 750. الفحص **داخل `analyze-application` قبل نداء النموذج**. **مُثبَت:** 3 نداءات تمرّ على حصة 3، الرابع يُرفض، والإفراج يُعيد وحدة.
فشل **قبل** النموذج ⇒ استرداد. فشل **بعده** ⇒ لا استرداد (المال أُنفق). ونفاد الحصة يترك الطلب **مقروءاً يدوياً** — `D4` سليم.

### الدفعة 4 — تقرير الشفافية (`D24`)
تصدير HTML لكل طلب: الدرجة، التفصيل، التبرير، **إصدار الموجّه والنموذج**، و**من غيّر الحالة ومتى**. الإشعار الاستشاري **داخل** الوثيقة لا حولها فقط. مصرَّح مرتين: بوابة المسار + فحص العضوية في الدالة.

### الدفعة 5 — الفرز المُعمّى + السعودة
**المُعمّى:** مرحلة تجهيل منفصلة، والتقييم لا يرى إلا النصّ المجهّل — **الملف الأصلي لا يصل المرحلة الثانية إطلاقاً**. فشل التجهيل ⇒ **فشل التشغيل**، لا رجوع للأصل. **اختياري ومطفأ افتراضياً** (يضاعف الكلفة).
> **`prompts.ts`: 46 إضافة، صفر حذف** — الموجّه التقييمي سليم حرفياً كما يفرض §10.8.

**السعودة:** ⚠️ **النظام لا يستنتج الجنسية إطلاقاً.** الموظف البشري يسجّلها، عند **مرحلة المقابلة أو العرض فقط**، وثلاث حالات (نعم/لا/**لم يُسجَّل**). **خارج درجة الملاءمة تماماً.**

## الجزء الثالث: ما تفعله أنت — بالتسلسل

### 🔴 المرحلة 1 — قبل أي نشر (30 دقيقة)

**1. راجع الكود ثم ادمج الـPR.** الفرع `claude/audit-august-2026-pajah5`.

**2. طبّق الهجرات على بيئة تجريبية أولاً — لا الإنتاج.**
```bash
supabase db push
```
ستطبّق `0012` → `0017`. راجع `0013` تحديداً: يضيف عموداً ويعيد تعبئته.

**3. اضبط إعدادات مهمة التنظيف** — **بدونها لن تعمل مهمة الحذف اليومية** (التزام `D8`):
```sql
alter database postgres set app.housekeeping_url =
  'https://<ref>.supabase.co/functions/v1/housekeeping';
alter database postgres set app.housekeeping_key = '<anon key>';
```
ثم أعد تشغيل `0012`. **`0012` سيصرخ `WARNING` إن لم تفعل** — وهذا مقصود.

**4. انشر الدوال الطرفية:**
```bash
supabase functions deploy submit-application analyze-application send-email
supabase functions deploy talent-upload talent-analyze
```

**5. اضبط أسرار الدوال الجديدة:** `SITE_URL` · `THROTTLE_SALT` · و`TURNSTILE_SECRET_KEY` (**مطلوب فعلياً الآن** — منصة المواهب تفشل مغلقة بدونه).

**6. أنشئ دلو `talent-cvs`** — تنشئه `0017`، تأكّد فقط أنه **خاص** (`public = false`).

### 🟠 المرحلة 2 — إعدادات تخصّك أنت (ساعة)

**7. الصق قوالب البريد العربية يدوياً** في Dashboard ← Authentication ← Email Templates من `supabase/templates/`. **قبل ذلك الإنتاج يرسل بالإنجليزية.**

**8. راجع `vercel.json`** — إن كان Root Directory عندك جذر المستودع لا `srp/`، **انقل الملف للأعلى وإلا لن يُقرأ**.

**9. اضبط حصص العملاء الحاليين:**
```sql
update organizations set monthly_analysis_quota = 150, plan_code = 'starter'
where slug = '<slug>';
```
الافتراضي 25 (تجربة).

**10. أدخل نطاقك في نطاقات** من `/admin/settings` — اختياري.

### 🟡 المرحلة 3 — قرارات لم أتخذها نيابةً عنك

**11. 🔴 موقع البيانات — أخطر بند مفتوح.** سِيَرك في **سيول** (`ap-northeast-2`)، ومنتجك سعودي. مسألة **PDPL قبل الأداء**. منطقة Supabase **لا تتغير في مكانها** — تحتاج مشروعاً جديداً وهجرة.
> **افعلها قبل أن تصل بيانات عملاء حقيقيين.** وقد ضاعفت منصة المواهب هذه المخاطرة لأنها **تنشر** بيانات شخصية.

**12. تحقّق أن مفتاح Gemini من الطبقة المدفوعة.** صفحة خصوصيتك **تَعِد المتقدمين** بعدم التدريب على بياناتهم — والمجاني لا يضمن ذلك.

**13. قرّر تسعير الحصص فعلياً** — بنيتُ الآلية بأرقام صفحتك الحالية.

**14. لمنصة المواهب:** العمود السوقي الأول (مدينة + تخصص) · مجانيتها · من يدفع.
